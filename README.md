# অফিস খরচ (Office Expense Manager)

সহজ, সুন্দর এবং মোবাইল-বান্ধব অফিস ফান্ড ও খরচ ব্যবস্থাপনা ওয়েব অ্যাপ্লিকেশন। সমগ্র ইউজার ইন্টারফেস সম্পূর্ণ বাংলায় তৈরি এবং সাধারণ বা নন-টেকনিক্যাল ব্যবহারকারীদের সুবিধার্থে বড় বাটন ও স্পষ্ট লেবেল দিয়ে ডিজাইন করা হয়েছে।

---

## 🌟 প্রযুক্তি স্ট্যাক (Tech Stack)

- **ব্যাকএন্ড**: Laravel 11 (PHP 8.3)
- **ফ্রন্টএন্ড**: React 19 + Inertia.js
- **স্টাইলিং**: Tailwind CSS v4
- **ফন্ট**: Hind Siliguri (Google Fonts)
- **চার্ট**: Recharts
- **এক্সপোর্ট**: Excel (.xlsx) এবং প্রিন্ট/PDF
- **ডেটাবেস**: SQLite (কোনো জটিল সেটআপ ছাড়াই সাথে সাথে কাজ করে) এবং মডিউলার `storage.js` লেয়ার (ভবিষ্যতে Supabase-এ সুইচ করার জন্য প্রস্তুত)

## 🚀 কীভাবে রান করবেন (How to Run)

### ১. ডিপেনডেন্সি ও সেটআপ
প্রজেক্টের ডিরেক্টরিতে যান:
```bash
cd office-expense-laravel
```

যদি নতুন করে ইনস্টল করতে চান:
```bash
composer install
npm install
```

### ২. ডেটাবেস মাইগ্রেশন ও ডেমো ডেটা লোড
```bash
php artisan migrate --seed
```
*(এটি স্বয়ংক্রিয়ভাবে ডিফল্ট ক্যাটাগরি এবং পরীক্ষার জন্য আদর্শ ডেমো হিসাব তৈরি করবে।)*

### ৩. অ্যাপ রান করা
দুটি টার্মিনালে রান করতে পারেন অথবা অ্যাসেট বিল্ড করে সরাসরি সার্ভার চালাতে পারেন:

**পদ্ধতি ক: সরাসরি বিল্ড ও রান (সবচেয়ে সহজ)**
```bash
npm run build
php artisan serve
```
এরপর ব্রাউজারে প্রবেশ করুন: **http://127.0.0.1:8000**

**পদ্ধতি খ: লাইভ ডেভেলপমেন্ট মোড**
- টার্মিনাল ১: `php artisan serve`
- টার্মিনাল ২: `npm run dev`

## 📖 প্রতিটি পেজের ব্যবহার নির্দেশিকা (How to Use)

### ১. হোম ড্যাশবোর্ড (হোম)
- **আজকের খরচ**: আজকের তারিখে মোট কত খরচ হয়েছে তা একনজরে প্রদর্শন করে।
- **ব্যালেন্স স্ট্যাটাস ব্যানার**: বর্তমান ব্যালেন্স অবস্থা প্রদর্শন করে (যেমন: "আপনাকে ফেরত দিতে হবে ৳২০০" বা "আপনি পাবেন ৳২০০" বা "হিসাব সমান")।
- **দ্রুত অ্যাকশন কার্ড**: বড় বোতাম দিয়ে সরাসরি "টাকা নিলাম (অগ্রিম)" অথবা "নতুন খরচ" এন্ট্রি করা যায়।
- **সাম্প্রতিক লেনদেন**: সর্বশেষ ভাউচার ও অগ্রিম গ্রহণের তালিকা।

### ২. টাকা গ্রহণ / অগ্রিম তহবিল (Advances)
- অফিস বা কোম্পানি থেকে কোনো কাজের জন্য অগ্রিম টাকা নেওয়া হলে এখানে এন্ট্রি করা হয়।
- **ফিল্ডসমূহ**: তারিখ ও সময়, কে টাকা গ্রহণ করেছেন (কর্মী), কার থেকে নেওয়া হয়েছে (কোম্পানি ফান্ড/ম্যানেজার), টাকার পরিমাণ (৳), এবং উদ্দেশ্য।
- প্রতিটি অগ্রিমের পাশে খরচ ও ব্যালেন্স প্রদর্শিত হয়।
- হিসাব মেলানোর পর **"পরিশোধ হয়েছে"** বোতামে চাপ দিয়ে নিষ্পত্তি রেকর্ড করা যায়।

### ৩. খরচ এন্ট্রি ও ভাউচার (Expenses)
- প্রতিদিনের যেকোনো অফিস খরচের তালিকা ও নতুন ভাউচার যোগ করার ব্যবস্থা।
- **ফিল্ডসমূহ**: তারিখ, খরচের পরিমাণ, খাত/ক্যাটাগরি (যাতায়াত, নাস্তা, প্রিন্টিং, ইন্টারনেট, অন্যান্য + নিজেই নতুন খাত তৈরির সুবিধা), কে খরচ করেছেন, সংশ্লিষ্ট অগ্রিম তহবিল নির্বাচন, ইভেন্ট ট্যাগ এবং রসিদ বা ভাউচারের ছবি।
- যুক্ত করা রসিদের ছবি বড় করে দেখা এবং ডাউনলোড করার সুবিধা রয়েছে।

### ৪. ব্যালেন্স ও দেনা-পাওনা হিসাব (Balance Logic - সবচেয়ে গুরুত্বপূর্ণ)
এই পেজে দুটি ভিউ রয়েছে:
- **আমার হিসাব (My View)**: কর্মী হিসেবে আমি কোম্পানি থেকে কত টাকা পাবো ("আপনি পাবেন ৳X") অথবা কোম্পানিকে কত ফেরত দিতে হবে ("আপনাকে ফেরত দিতে হবে ৳X")।
- **কোম্পানি ভিউ (Company View)**: কোম্পানির সার্বিক হিসাব—কোম্পানি মোট কত টাকা পাবে এবং বিভিন্ন কর্মীকে মোট কত টাকা প্রদান করতে হবে।
- **ব্যালেন্স সূত্র**: `ব্যালেন্স = অগ্রিম গ্রহণ (Advance) - মোট খরচ (Expenses)`
  - **ব্যালেন্স > ০ হলে**: কর্মী কম খরচ করেছেন, তাই অবশিষ্ট উদ্বৃত্ত টাকা কোম্পানিকে ফেরত দিতে হবে (বার্তা: **"আপনাকে ফেরত দিতে হবে ৳X"**)।
  - **ব্যালেন্স < ০ হলে**: কর্মী অগ্রিমের চেয়ে বেশি খরচ করেছেন, তাই বাড়তি টাকা অফিস থেকে পাবেন (বার্তা: **"আপনি পাবেন ৳X"**)।
  - **ব্যালেন্স == ০ হলে**: **"হিসাব সমান"**।
- **পরিশোধ হয়েছে (Settled)**: এই বোতাম চাপলে নিষ্পত্তির তারিখ ও নোট সংরক্ষণ হয় এবং ব্যালেন্স সমান হিসেবে গণ্য হয়।

### ৫. ইভেন্ট বাজেট ট্র্যাকিং (Events)
- বার্ষিক সভা, টিম পার্টি, ক্লায়েন্ট সম্মেলন বা বিশেষ আয়োজনের জন্য বাজেট নির্ধারণ করা যায়।
- খরচের সময় নির্দিষ্ট ইভেন্ট ট্যাগ করলে ইভেন্ট পেজে স্বয়ংক্রিয়ভাবে মোট খরচ ও প্রগ্রেস বার দেখা যায়।
- **রেড অ্যালার্ট**: খরচ বাজেটের বেশি হয়ে গেলে প্রগ্রেস বারটি লাল রঙে পরিবর্তিত হয়ে সতর্কবার্তা দেখায়।
- খাতওয়ারী (Category-wise) খরচের বিবরণ প্রদর্শিত হয়।

### ৬. রিপোর্ট ও বিশ্লেষণ (Reports)
- **ফিল্টার**: নির্দিষ্ট তারিখের রেঞ্জ, কর্মী, ক্যাটাগরি বা ইভেন্ট অনুযায়ী ফিল্টার করার সুবিধা।
- **দৈনিক খরচ টেবিল**: তারিখ অনুযায়ী কোন দিন কত টাকা মোট খরচ হয়েছে তার তালিকা।
- **ভিজ্যুয়াল চার্ট**: 
  - খাতওয়ারী খরচের পাই চার্ট (Pie Chart)
  - মাসওয়ারী খরচের বার চার্ট (Bar Chart)
- **কর্মী সামারি টেবিল**: কে কত অগ্রিম নিয়েছেন, কত খরচ করেছেন এবং বর্তমান ব্যালেন্স কত।
- **এক্সপোর্ট**:
  - **এক্সেল ডাউনলোড (.xlsx)**: একক ক্লিকে ফিল্টার করা ডেটা এক্সেলে ডাউনলোড হবে।
  - **প্রিন্ট / PDF**: পরিষ্কার প্রিন্ট লেআউটে সরাসরি প্রিন্ট বা PDF সেভ করার সুবিধা।

## ☁️ ভবিষ্যতে Supabase বা মাল্টি-ইউজার সিঙ্ক যুক্ত করার নিয়ম

এই প্রজেক্টের সমস্ত ডেটা অ্যাক্সেস এবং ব্যালেন্স ক্যালকুলেশন লজিক `resources/js/storage.js` ফাইলে অত্যন্ত পরিষ্কারভাবে আলাদা রাখা হয়েছে। ভবিষ্যতে Supabase ব্যবহার করতে চাইলে নিচের যেকোনো একটি উপায় অনুসরণ করতে পারেন:

### উপায় ১: ফ্রন্টএন্ডে Supabase Client ব্যবহার করা
১. Supabase ক্লায়েন্ট লাইব্রেরি ইনস্টল করুন:
```bash
npm install @supabase/supabase-js
```
২. `resources/js/storage.js` ফাইলের শুরুতে Supabase ক্লায়েন্ট ইনিশিয়ালাইজ করুন:
```javascript
import { createClient } from '@supabase/supabase-js';

const supabaseUrl = 'https://YOUR_PROJECT_ID.supabase.co';
const supabaseKey = 'YOUR_ANON_KEY';
export const supabase = createClient(supabaseUrl, supabaseKey);
```
৩. `storage.js` এর `getAdvances`, `saveExpense` ইত্যাদি ফাংশনের ভেতরে `localStorage`-এর বদলে Supabase কুয়েরি বসিয়ে দিন:
```javascript
// উদাহরণ:
async getAdvances() {
    const { data } = await supabase.from('advances').select('*');
    return data;
}
```

### উপায় ২: Laravel এর মাধ্যমে সরাসরি Supabase PostgreSQL কানেক্ট করা (সুপার সহজ)
যেহেতু এটি Laravel অ্যাপ, তাই কোনো ফ্রন্টএন্ড কোড পরিবর্তন না করেই ব্যাকএন্ডে Supabase কানেক্ট করা যায়:
১. Supabase ড্যাশবোর্ড থেকে Database URI সংগ্রহ করুন।
২. আপনার `.env` ফাইলে শুধু ডেটাবেস সংযোগ পরিবর্তন করুন:
```env
DB_CONNECTION=pgsql
DB_HOST=db.YOUR_PROJECT.supabase.co
DB_PORT=5432
DB_DATABASE=postgres
DB_USERNAME=postgres
DB_PASSWORD=YOUR_SUPABASE_PASSWORD
```
৩. মাইগ্রেশন রান করলেই সব টেবিল Supabase ক্লাউডে স্বয়ংক্রিয়ভাবে তৈরি হয়ে যাবে:
```bash
php artisan migrate
```

## 🧪 পরীক্ষিত টেস্ট কেস (Tested Balance Logic)

অ্যাপ্লিকেশনটিতে নিচের টেস্ট কেসগুলো সফলভাবে যাচাই করা হয়েছে:
1. **অগ্রিম ২০০০ ৳, খরচ ২২০০ ৳**:
   - সূত্র: ২০০০ - ২২০০ = -২০০ ৳
   - ফলাফল: কর্মী কোম্পানি থেকে অতিরিক্ত ২০০ টাকা পাবেন (**"আপনি পাবেন ৳২০০"**)।
2. **অগ্রিম ২০০০ ৳, খরচ ১৮০০ ৳**:
   - সূত্র: ২০০০ - ১৮০০ = +২০০ ৳
   - ফলাফল: কর্মী কোম্পানিকে ২০০ টাকা ফেরত দেবেন (**"আপনাকে ফেরত দিতে হবে ৳২০০"**)।
3. **অগ্রিম ১৫০০ ৳, খরচ ১৫০০ ৳**:
   - সূত্র: ১৫০০ - ১৫০০ = ০ ৳
   - ফলাফল: **"হিসাব সমান"**।
